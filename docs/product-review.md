# بازطراحی محصول و تجربهٔ کاربر — ۲۰۲۶/۱۰/۱۳

## تصمیم محصول

خانه تابلو سازان یک مارکت‌پلیس خدمات تابلوسازی است: کاربر باید بتواند نوع تابلو را بشناسد، اجرای متخصص را بررسی کند، نیازش را ثبت کند و پیشنهادهای اجرا را مقایسه کند. گالری هوش مصنوعی و مجله، ابزار تصمیم‌گیری در همین مسیرند. صفحهٔ اصلی اکنون «ثبت درخواست تابلو» را به‌عنوان اقدام اصلی دارد؛ انتخاب خدمت، متخصص و الهام مسیرهای مکمل‌اند.

درخواست تازهٔ مالک، انتخاب رنگ‌ها و هر دو تم jeddy.ir را جایگزین محدودیت قبلی سفید/قرمز کرد. رنگ‌های اصلی با computed style مرجع در مرورگر بررسی شدند. استودیوی تابلو همچنان حذف است.

## یافته‌ها و تغییرات اجراشده

| مسئله | تغییر نهایی |
| --- | --- |
| قرمز و تم فقط روشن با مرجع انتخاب‌شده هم‌خوان نبود | رنگ‌های آبی/اسلیت مرجع در tokens؛ تم روشن و تاریک واقعی، انتخاب دستگاه، دکمهٔ تم و ذخیرهٔ ترجیح |
| صفحهٔ اصلی بیشتر یک گالری بود تا مسیر سفارش خدمات | بازچینی کامل: معرفی و سفارش → خدمات → نمونه‌کار → مراحل همکاری → متخصصان → الهام → مجله → عضویت متخصص → پرسش‌ها |
| خدمات صفحهٔ مرکزی برای شناخت و انتخاب نداشتند | `/services/` با جست‌وجوی نام، کاربرد و متریال؛ کارت‌های کاربرد/متریال، جزئیات و راهنمای انتخاب |
| سفارش از صفحهٔ یک خدمت، همان خدمت را انتخاب نمی‌کرد | انتقال خدمت فعال با `?service=slug` به مرحلهٔ انتخاب؛ حفظ امکان تغییر قبل از ادامه |
| کاربر مبتدی مسیر واضحی نداشت | مسیر `?guidance=1` گزینهٔ «نیاز به راهنمایی» را انتخاب می‌کند؛ عکس و توضیح ساده مبنای گفت‌وگوست |
| فهرست متخصصان همه را بدون فیلتر نشان می‌داد | جست‌وجوی نام/توضیح، فیلتر شهر و خدمت، مرتب‌سازی امتیاز/تجربه، صفحه‌بندی ۱۲ موردی و حفظ فیلترها بین صفحات |
| بخش‌های سایت چند زبان بصری داشتند | بازنویسی experience.css برای صفحات عمومی، مقاله، گالری، فرم‌ها، پنل‌ها، درخواست و گفت‌وگو؛ همه از همان توکن‌های دو تم استفاده می‌کنند |
| کاربران ممکن بود تصاویر AI را اجرای واقعی فرض کنند | مسیر نمونه‌کار و گالری الهام جداست؛ نوع تصویر در کارت‌ها و متن راهنما مشخص است |

## معماری اطلاعات

- خدمات: شناخت انواع تابلو، جزئیات، متریال و شروع درخواست با همان انتخاب.
- نمونه‌کارها: بررسی اجرا و یافتن متخصص مرتبط؛ فیلترهای موجود حفظ شده‌اند.
- متخصصان: کشف بر اساس شهر و تخصص؛ پروفایل، نمونه‌کار و درخواست مستقیم قیمت.
- گالری الهام و بورد: کشف و ذخیرهٔ ایده، سپس اتصال مرجع‌ها به درخواست.
- مجله: راهنمای انتخاب و همکاری؛ صفحات و دادهٔ ساختاریافتهٔ سئو حفظ شده‌اند.
- میز کار مشتری: درخواست، پیشنهادها، مقایسه، گفت‌وگو، انتخاب و ثبت نظر پس از پایان.
- میز کار متخصص: درخواست‌های مرتبط، پیشنهادها، گفت‌وگو، پروفایل و مدیریت نمونه‌کار.
- مدیریت محتوا: ورود مستقل از نقش تابلوساز، با مجوزهای staff موجود.

## صداقت محصول

قیمت از پیشنهاد متخصص و مشخصات پروژه می‌آید؛ عدد یا برآورد ساختگی در صفحهٔ خدمات اضافه نشده است. مسیر همکاری همان جریان درخواست، پیشنهاد، گفت‌وگو و اجراست. زیرساخت پرداخت و اعلان‌ها به معنی سرویس پرداخت یا ارسال فعال نیست. بورد فعلی به مرورگر وابسته است و همین محدودیت در راهنمای کاربر نوشته شده؛ ذخیرهٔ بین دستگاه‌ها نیازمند قابلیت جداگانه است.

## اجرای فنی و بررسی

هیچ مدل، مهاجرت یا وابستگی جدیدی اضافه نشده است. تغییرات رفتاری در forms/selectors/views برنامه‌های catalog و vendors و شروع ویزارد requests قرار دارند. URLهای قبلی حفظ شده‌اند. خدمات فقط فعال و متخصصان فقط فعال/تأییدشده نمایش داده می‌شوند. اعتبارسنجی فیلترها در فرم است و خطای نامعتبر با ۴۰۰ و خطای کنار ورودی نشان داده می‌شود.

تست تعداد کوئری: فهرست خدمات ۱ کوئری؛ فهرست متخصصان با کارت‌ها، شهر و خدمات ۵ کوئری ثابت برای صفحهٔ ۱۲ موردی. آزمون‌های فیلتر، صفحه‌بندی، حفظ انتخاب‌ها، خدمت غیرفعال و نیاز به راهنمایی اضافه شده‌اند.

نتیجهٔ نهایی: ۲۰۵ تست Python و ۹ تست JavaScript موفق؛ ruff lint/format، Django check، missing migrations و manifest استاتیک production موفق. تم‌ها و مسیر خدمات تا انتخاب تابلو و فیلتر متخصصان در مرورگر واقعی بررسی شدند. پنل‌های خصوصی با رندر فقط‌خواندنی همان view بررسی شدند؛ حساب، مجوز یا قرارداد تازه‌ای ساخته نشد.
